# Contributing

Issues and pull requests are welcome. Keep checks read-only and useful without root, use stable dotted IDs, return `skipped` when permission is unavailable, and provide evidence plus safe remediation. Add mocked fixtures and tests for new parsers; never make tests depend on a running Docker daemon or systemd host.

Before opening a change, run the commands listed in the README. Do not add automatic cleanup, repair, upload, dashboard, or cloud dependencies.
