# Security policy

Please report suspected vulnerabilities privately to `security@homelab-doctor.example` with reproduction steps, affected version, and impact. Do not include real credentials or diagnostic bundles containing unreviewed data. We will acknowledge reports within seven days and coordinate a fix before public disclosure.

Homelab Doctor is designed for read-only collection. It rejects bundle symlink outputs and unsafe archive names, redacts common secrets, and makes no network upload. Treat generated bundles as sensitive nonetheless and inspect them before sharing.
